## 动效时序规范

动效是视频节奏感的核心来源，不能只写"淡入"了事，必须精确到毫秒级。

### 时间参数

| 动效类型 | 持续时间 | 缓动曲线 | 说明 |
|---------|---------|---------|------|
| 元素入场 |  |  | 推荐 ease-out，元素从不可见到可见 |
| 元素退场 |  |  | 推荐 ease-in，比入场更快 |
| 强调动画 |  |  | 脉冲/放大/高亮，用于关键数据出现 |
| 转场切换 |  |  | 场景间过渡，比元素动效更长 |
| 数字滚动 |  |  | 金额、参数等数据动画 |
| 字幕出现 |  |  | 与口播节奏匹配，不能快于语速 |

### 触发顺序

同屏多个元素出现时，必须有明确的时间差，禁止同时弹出：

```
示例（同屏3个元素）：
  标题        → 0ms     入场
  产品卡片    → +300ms  入场
  参数数字    → +600ms  入场（带数字滚动）
```

### 节奏原则

- 信息密集的段落，动效要快，不能拖节奏。
- 强调性内容（结论、关键数据），动效可以稍慢，给观众消化时间。
- 转场时画面全空不超过 0.5 秒，避免节奏断裂。
- 禁止同一类元素用两种不同的入场方式（坑2：风格统一）。
