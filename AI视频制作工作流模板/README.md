# AI 视频制作工作流模板

本模板用于把视频制作从临时创作变成可复用、可检查、可积累的生产流程。优先服务建筑装饰、装配式装修、辅材产品、旧改案例、招商培训和一人公司内容生产。

## 使用顺序

1. 先填写 `templates/01_生产简报.md`，明确平台、目标、素材和核心信息。
2. 用 `templates/02_脚本检查.md` 检查口播稿或文案是否适合视频。
3. 用 `templates/03_DESIGN.md` 锁定视觉系统（含动效时序规范），不先写视频代码。
4. 用 `templates/04_分镜时间码表.md` 拆分镜头、口播、画面元素、素材和精确触发时间码。
5. 按 `选择生产路线.md` 选择 HyperFrames、FFmpeg、剪映或人工剪辑介入方式。口播视频必读 `rules/口播视频合成架构.md`。
6. 制作后按 `checklists/最终MP4验收清单.md` 检查最终成片。
7. 按 `templates_07_交付说明模板.md` 创建交付说明文件，记录交付物元信息。
8. 完成后填写 `templates/05_版本复盘.md`，把踩坑沉淀成下一次规则。
9. 将可复用动效组件注册到 `templates_06_复用组件库.md`。

## 规则文件

- `rules/口播视频规则.md` — 人像状态、时间码、安全区、常见问题预防。
- `rules/素材使用规则.md` — 素材引用、禁止擅改、推荐处理方式。
- `rules/口播视频合成架构.md` — 双轨分离原则、合成流程、常见错误与防御。

## 基本原则

- 最终 MP4 才是验收事实，预览和截图只作为中间证据。
- 用户提供的 Logo、产品图、施工图、报价表、案例照片默认不得重画、替换用途或改变含义。
- 先做 30-60 秒短视频模板，跑通后再扩展到 3-5 分钟培训或课程视频。
- 每次返工都要转化为规则、组件或清单，避免下次重复踩坑。
- 口播视频的图文叠加层和真人视频必须分离生产，由 FFmpeg 最终合成。
- 动效必须有精确的时间参数（持续时间、缓动曲线、触发顺序），不允许只写"淡入"。
